# christmas-tree v17.6

An interactive, single-file 3D Christmas tree rendered on HTML5 Canvas (no dependencies, no build step).

## Highlights

- ~1,700 procedurally generated needle points with depth-based glow
- 250 twinkling fairy lights, 22 ornaments and a golden star topper
- Drag to rotate (with inertia), scroll to zoom, animated snowfall
- Gifts under the tree, gold gradient headline
- Responsive layout for desktop and mobile
- "Save image" exports a PNG snapshot

## Run locally

Just open `index.html` in any modern browser — everything is inline.

## Deploy

GitHub Pages serves `index.html` from the repository root (`main` branch).
